# Decisões de Arquitetura

- Next.js App Router com Server Components por padrão.
- Route Handlers para fronteiras HTTP.
- Prisma isolado em `packages/database`.
- npm workspaces sem orquestrador adicional.
- sessão de desenvolvimento atrás de uma interface.
- provedores de IA atrás de adapters desativados.
- campos JSON apenas onde a flexibilidade é parte do domínio.
