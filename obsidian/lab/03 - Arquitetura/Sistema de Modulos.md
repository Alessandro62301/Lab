# Sistema de Módulos

Um módulo possui:

- definição global;
- estado por workspace;
- configurações JSON opcionais;
- vínculo opcional a um projeto;
- rota interna.

O registro em código controla navegação e metadados. O banco controla habilitação e configuração. O [[Data Inbox]] usa esse mecanismo sem exigir uma aplicação separada.
